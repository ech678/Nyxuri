## 证据、覆盖范围与读法

- 原树 909 个文件均核验内容与可执行位；[MANIFEST](../references/clavis-15403b9/MANIFEST.json) 记录 Git blob、mode、字节数。
- [全树路径映射](../references/clavis-15403b9/SOURCE-MAP.json) 覆盖全部 909 个文件，包括资产、脚本、许可证、native、测试和历史文档；同名候选和职责替代明确标记，文件存在不证明行为一致。
- [依赖附件](../references/clavis-15403b9/DEPENDENCIES.json) 覆盖原版 549、当前 561 个 QML/JS 文件；每个节点有 imports、直接源码依赖、native URI、静态资产、路径字面量、配置、WidgetState、required 属性、动态 source/model/manager/target/command 和处理器位置。按 direct_source_dependencies 递归读取，遇到循环只读一次；原版 native URI 对应插件目录完整清单另列。
- [交互源码附件](../references/clavis-15403b9/INTERACTIONS.json) 保存原版处理器的完整源码摘录。下方逐输入入口表覆盖模块及共享控件；叶子处理器不能离开窗口宿主、绑定和注入对象单独搬运。
- 依赖附件是保守静态候选图，保留歧义与动态入口，不能证明最小运行闭包。具体功能的装配链与隐式上下文见下表；字符串拼接 URL、动态图标、设备和运行注入须按记录现场核对。不得把静态扫描升级为“完整行为已验证”。
- 当前路径与 SHA-256 描述盘点时的工作区。后续有源码变化须重读差异，可显式运行参考目录的 audit-inventory.py 更新附件；该命令只写审计附件，不改提取的 shell/ 原树。

普通 Bar 的音量、麦克风、亮度每次 wheel 按 angleDelta.y 正负增减 0.05；音量 backend 限制 0..1 并取消静音，亮度普通下限 0.01、allowZero 才可归零。LongStatusItem 还支持 y 或 x delta 的音量/麦克风/亮度滚轮。当前普通 Bar 改经 ActionGateway；事件命中、参数、设备写入和回读均未实测。
