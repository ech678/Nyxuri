# 双语国际化引擎

## 语言选择

`get_lang()` → `"zh"` 或 `"en"`，由 `$LANG` / `$LC_ALL` 包含 `"zh"` 决定；`set_lang()` 可强制切换并清空缓存。

## msg() 协议

```python
msg(key: str, *args) -> str
```

1. 查 `translations.toml` 中 `[key]` section
2. 取当前语言字段 `zh` 或 `en`（en 为 fallback）
3. 用 `str.format(*args)` 填充参数
4. 无参数时结果缓存到 `_MSG_CACHE`（同一进程内重复调用免查）

**缺失 key**：返回 `key` 本身（或 `key (arg1, arg2)`），不抛异常。

## text() 快捷函数

```python
text(zh: str, en: str) -> str
```

一次性双语字符串，不走 translations.toml；用于诊断/状态行等不值得建键的场景。

## translations.toml 结构

```toml
[key_name]
zh = "中文文案 {Placeholder}"
en = "English text {placeholder}"
```

模板变量由 `_load_translations()` 自动注入：`PROJECT_NAME`、`Colors.*`  ANSI 转义码。

## 扩展规则

加新键：在 `translations.toml` 加 `[键名]` section + `zh` + `en` 两个字段。
`test_i18n.py` 会校验：无孤儿键、无缺失字段、参数占位符一致。
