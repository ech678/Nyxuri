# Nyxuri 设计哲学与架构愿景

> 极简不是风格，是秩序感：几何精度（对齐规整）+ 做减法（砍掉一切不必要的）。

---

## 1. 核心精神

1. **白纸洁癖**：系统是一张纯白特种画纸。Nyxuri 带来的每一处改动都必须可追溯、可撤回、零孤儿残留。干干净净地来，清清白白地退。
2. **反失控感与无熵**：依赖地狱、体积膨胀、运行时黑盒本质上都是系统熵增。零未声明依赖，纯标准库能做就决不外引包。
3. **流畅但不越俎代庖**：安装过程少打断；真正需要取舍与破坏性操作时，列清事实，把选择权还给用户。
4. **架构对称性**：
   - **空间对偶**：仓库源码（`configs/`）是只读蓝图，用户系统（`~/.config/`）是生活空间，中轴（`deploy.atomic`）以哈希比对与原子替换连接，互不侵犯。
   - **模块对齐**：外部供给（`pkg`）、内部渲染（`deploy`）、外部诊断（`doctor`）、内部回溯（`state`）四象限各司其职，消除缝合怪与特判特例。

---

## 2. 演进原则

- **底座先行、契约冻结**：先搭齐底层公共接口与测试样本并冻结契约，再逐一接入具体桌面业务。
- **一切皆可选 (Everything is Optional)**：Shell 与合成器（Niri、Hyprland 等）按需组装，不强制死锁单一组件。
- **纯标准库驱动**：守护纯 Python 标准库零依赖基准，保证 `arch=('any')` 免编译分发与秒级测试闭环。
