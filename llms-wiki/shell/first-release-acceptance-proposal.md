# Nyxuri Shell 首版开发与验收清单

评估依据：官方仓库 [ech678/Nyxuri @ dc11133c](https://github.com/ech678/Nyxuri/tree/dc11133c6f0f216fe998786f13a50ed088d98fc1)，2026-11-22。以下是讨论确认的方向与建议验收用例，不是上游已实现或已经通过的结论。

**开发顺序：独立启动与恢复 → 一条完整日用链 → 多栏与弹窗 → 真实 Niri 长跑 → 稳定标签。** 先验证能日用、坏了能恢复，再加功能。首版只承诺原版 Niri；Mango 暂列实验。长期允许 Shell 脱离 Nyxuri 管理器运行，不因这一目标立即拆仓库。

## 1. 独立启动与恢复

- **状态所有权。** 窗口、工作区、输出以 Niri 为准；主题、布局和弹窗属于 Shell。插件启停：独立模式读写 Shell 配置，托管模式只认管理器账本；显式选模式，不双向同步。管理器不可用时，已载入的桌面继续运行，禁用依赖管理器的开关并说明原因，不切换权威来源。
- **断开和重连。** Shell 保持可见，时钟、主题和已有通知不受影响。工作区显示不可用，窗口命令立即明确失败，不排队、不重放。只有在重连并从 Niri 取到全量状态后，才恢复相应操作。
- **安全启动。** 配置先校验，升级前留可恢复副本。坏配置不写回，启动内建最小栏和启动器，显示哪一项失败，允许用户选择恢复或修复。重启 Shell 不应要求退出 Niri。
- **退出条件。** 同一次实机验证覆盖：无管理器启动、托管时停管理器、Niri 连接断开期间点击并重连、坏配置启动、仅重启 Shell。保存启动和故障日志，验证坏配置原件未变、没有错误命令在重连后执行。

## 2. 日用链和安全边界

- **首版范围。** 状态栏、工作区、应用启动、通知、基础快设、主题设置与已验证锁屏形成一条日用链。动态岛、Mango 功能对等、Noctalia 功能对齐、完整第三方生态不阻挡首版。
- **插件失败可见。** 默认只启用内建组件。区分「已配置」与「已运行」，可检测的可选插件加载失败要显示并能停用。第三方 QML 与宿主同进程，不承诺进程级故障隔离；不把开关状态当作健康状态。
- **锁屏单验。** 自研锁屏在认证、挂起唤醒、锁住时禁止热卸载和失败恢复通过前，不做默认。继续用已经验证的锁屏方式，不用普通覆盖窗口代替锁屏。
- **退出条件。** 一个连续实机会话完成：启动应用、切工作区、接收与清理通知、操作快设、换主题、锁定与唤醒；注入一次可选组件加载失败，确认核心链可用且错误不被吞。自研锁屏的缺失证据单列，不拿普通 UI 测试替代。

## 3. 多栏隔离与弹窗迁移

以 Shell 路线图为阶段依赖依据。先补逐栏运行时的字号、厚度等读写隔离，再验收多栏编辑器；外观密度与图标缩放可以稍后做。先用时钟弹窗试通 D5，再扩托盘、侧栏与启动器，锁屏和会话弹窗不照搬。

**决策记录草案：弹窗归逻辑状态栏，承载输出可以变。** 拔屏后，按拔屏前桌面布局从左到右、同列从上到下循环，跳过当前不存在或没有同一条栏的输出，选择下一块符合条件的屏。保留同一个打开状态与内容，不复制。无合格输出才关闭。选择布局顺序，而不是跟鼠标或设备枚举，是为了可预期；选择不换逻辑栏，是为了不把 A 栏的状态误带到 B 栏。

| 实机用例 | 预期 |
| --- | --- |
| 顶栏字号 1.0、底栏 1.3，切换编辑目标并重置顶栏 | 底栏的字号、厚度与运行状态不变 |
| 三屏拔中间，右屏仍有同一条栏 | 弹窗只在右屏保留一份，内容仍在 |
| 拔掉末尾屏或下一块没有同一条栏 | 循环并跳过不合格输出；无可用目标则关 |
| 单屏、双屏热插拔，横栏与竖栏组合 | 既有窗口不串栏；发起栏与屏幕边缘锚定正确 |

## 4. 稳定版放行

- **`nyxuri-git` 是滚动预览。** 稳定版锁定测试提交和运行时组合。Rust 重写和 `-bin` 包不是前置，也不把 AUR 上架视为日用验收。
- **固定一套原版 Niri + 真实 GPU 对照。** 记录提交、Niri、Quickshell、Qt、GPU/驱动、显示器与脚本版本。分别做 2 小时空闲、2 小时脚本交互，保留 100 轮回收检查；把 Shell、Noctalia 和壁纸进程的证据分开。先做同机对照并写明预热、采样和冷却范围，再定容差。
- **判定。** 按进程树的 PSS、私有内存和句柄观察持续趋势，并看停止操作后是否回到基线波动范围；RSS 峰值是诊断线索，不是单独的判退条件。保留原始采样、关键动作时间点及失败场景。无硬件证据、只跑了容器或测试跳过，一律不记通过。
- **不过怎么退。** 不发稳定标签；保留现有可用配置与锁屏。定位哪一关未通过，复测同一提交或修正版；坏配置时走最小 Shell，回退前保留用户原文件。
