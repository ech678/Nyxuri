# i18n — 双语文案引擎与翻译协议

> NyxNiri 引擎采用零依赖的轻量双语引擎（`zh` / `en`）。源码：`nyxniri/i18n.py`，
> 文案数据库：`nyxniri/translations.toml`。

## 核心设计

1. **环境自适应探测**：启动时根据 `LANG` 与 `LC_ALL` 环境变量自动推断，含 `zh` 则默认选中文，否则选英文。
2. **零运行时外部依赖**：基于 Python 3.11+ 标准库 `tomllib` 读取 `translations.toml`。
3. **常量预置替换**：加载 TOML 时自动把 `{PROJECT_NAME}` 与 `{Colors.XXX}` 宏替换为真实常量与 ANSI 色阶码，TUI 调用处无需拼接颜色。
4. **性能缓存**：无参数的固定文案由 `_MSG_CACHE` 缓存，`set_lang` 切换语言时自动失效。

## 两个接口动词

### 1. `msg(key, *args) -> str`（键值标准模式）

默认入口。从 `translations.toml` 中按 `key` 查找当前语言的模板并格式化：

```python
from nyxniri.i18n import msg

print(msg("msg_install_success"))
print(msg("msg_backup_created", snapshot_name))
```

- **容错保底**：若 `key` 不存在，直接返回 `key` 自身（有参数则附带参数），绝不抛异常中断流程。
- **参数解耦**：模板使用标准 Python `{}` 或 `{0}` 位置占位符，由 `msg()` 负责注入。

### 2. `text(zh: str, en: str) -> str`（轻量级逃生通道）

用于诊断、即时日志等不值得单独写入 TOML 字典的一次性双语状态行：

```python
from nyxniri.i18n import text

status_label = text("已跳过", "skipped")
```

杜绝了各模块内自行复制私有 `_text()` 工具函数的分裂现象。

## translations.toml 结构规范

```toml
[msg_preset_applied]
zh = "{Colors.GREEN}[✓]{Colors.RESET} 已切换 {Colors.BOLD}{}{Colors.RESET} 预设: {Colors.CYAN}{}{Colors.RESET}"
en = "{Colors.GREEN}[✓]{Colors.RESET} Switched {Colors.BOLD}{}{Colors.RESET} preset: {Colors.CYAN}{}{Colors.RESET}"
```

- 每个条目必须同时包含 `zh` 与 `en` 键，字段缺失会被契约测试捕获。
- 双语的参数占位符数量必须严格一致。

## 测试契约

由 `tests/test_i18n.py` 严格校验：
- 无孤儿键（代码引用的键必须在 TOML 中存在）。
- 无缺失翻译（每个键必须有中英双语）。
- 双语参数占位符个数绝对对齐。
