# TUI 设计系统

> 本页是 Nyxuri TUI（Textual inline）视觉与交互形态的唯一契约，以本页为准；交互原则见
> [tui-charter](tui-charter.md)，分期与状态见 [ROADMAP](../ROADMAP.md) T2。

参照系有两个：Claude Code / Codex CLI 给形态——界面不是一个“应用”，是终端里的一段对话；
Omarchy 安装器给版式——所有东西落在一条居中的栏里，共用同一条左边线。

---

## 1. 形态：记录 + 活动区

- **记录**：已经发生的事，以普通终端文本写进滚动历史。能滚、能复制、能搜，和 `ls` 的输出没区别。
- **活动区**：底部一块会动的区域，只放“现在要你决定的东西”或“正在跑的东西”。
  决定后它收成一行写进记录，下一个问题在它下面长出来。
- **原地展开，退出留痕**：Textual `run(inline=True, mouse=False)`；不进备用屏。活动区退出即清，
  留痕靠记录：决定后写一行结果进历史（`inline_no_clear` 会把整块框留下，不用）。
- **一次交互一次运行**：每个活动区是一次短的 inline 运行，运行之间用标准库输出写记录。
  sudo / pacman / `$EDITOR` 在两次运行之间直接接管终端，不需要 suspend。
- 没有页眉、页脚、标签页、侧栏、滚动条、背景色。

## 2. 色彩：跟随终端

- 只用终端 16 色，`ansi_color=True`，背景一律 `ansi_default`（透传）。
- 不写任何 hex。配色归终端主题管：Nyxuri Shell 换壁纸 → kitty 主题重渲染 → TUI 自动跟着变。

| 角色 | 取色 | 用途 |
| --- | --- | --- |
| 正文 | 默认前景 | 记录、选项 |
| 次要 | dim（亮黑） | 路径、详情行、提示行 |
| 强调 | ANSI magenta | 焦点指针、当前选项、待决定的字眼。全屏只此一色 |
| 成功 / 失败 / 警告 | green / red / yellow | 只染符号（`✓ ✗ !`），不染整行 |

强调色取 magenta 的理由：Shell 调色管线把终端 magenta 映射到 `surface_tint`
（`shell/commons/ThemePalette.js`），它跟着壁纸主色走，就是“终端的 accent”。
在 Noctalia 配色下 green 也映射到 primary，`✓` 与强调色同色，可以接受：二者都不铺面积。

## 3. 符号

只选宽度稳定（单宽）的字符，不跟罕见字体较劲。

| 符号 | 含义 |
| --- | --- |
| `●` | 一个步骤或动作（记录里的标题行） |
| `└` | 它的结果，缩进两格 |
| `❯` | 焦点指针 |
| `◉` / `◯` | 开 / 关 |
| `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏` | 进行中，只出现在活动区 |
| `✓` `✗` `!` | 成功 / 失败 / 需要注意 |

## 4. 空间

- **居中栏**（取自 Omarchy `install/helpers/presentation.sh`）：所有输出——字标、记录、活动区、提示行——
  落在同一条固定宽度的栏里，栏在终端里水平居中。栏宽固定 72 列（字标 51 列，在栏内居中，是左边线唯一的例外），
  左边距 = `(终端宽 − 栏宽) / 2`，全程一个值，所有行共用这条左边线。
- **只水平居中**：inline 形态下不做垂直居中，内容从光标处往下长。
- **窄终端**：终端 < 栏宽 + 4 时栏宽 = 终端宽 − 2，左边距 1 格；< 60 列时去掉框只留内容，列表的次要列先隐藏。
- **改宽**：活动区按新宽度重算边距并重排；已写进历史的记录不回头改。Textual inline 改宽时会清屏，
  运行中视口内的记录可能被抹掉，接受（M1 实测第 3 项，作者裁定）。
- **框**：同一时刻最多一个圆角细线框，宽度 = 栏宽，只框“需要你决定的东西”（列表、确认、输入）。记录里永远不画框。
- **节奏**：步骤之间空一行；结果紧贴所属步骤；不用分隔线。
- **对齐**：列宽按显示宽度算（中文 = 2）；栏内列共享左边线。
- **高度**：活动区限高 12 行，超出就在框内滚动，焦点行始终可见。
- **字标**：属于主菜单活动区的头部（强调色），随活动区一起重绘，改宽也不丢；决定后随活动区收掉，不写进记录。
  终端 < 20 行或 < 60 列时只留一行 `nyxuri <版本> · <配置目录>`。

## 5. 交互

- 键位：`↑↓` / `jk` 移动，`⏎` 确认，`space` 勾选，`esc` 返回，`1`–`9` 直选。
- 提示行：活动区下方一行 dim，只列当前焦点能按的键，如 `↑↓ 选择 · ⏎ 确认 · esc 返回`。
- 鼠标不追踪，终端原生选择、复制、滚动全部可用。
- 破坏性确认默认焦点在“取消”。
- Ctrl+C：活动区收掉，记录写一行 `└ 已取消`，终端干净退出。

## 6. 操作全覆盖

TUI 是完整的操作面，不是 CLI 的启动器。

- **动词对等**：`nyxuri/cli.py` 的 `COMMANDS` 里每个动词，在 TUI 里都有对应入口，参数在活动区里选或填，
  不要求用户记命令行。例外只有 `help`（TUI 自身就是帮助）、`test`（开发者沙箱）和 `enable` / `disable`（`on` / `off` 的别名）。
  对等关系由测试断言：`COMMANDS` 新增动词而 TUI 没接，测试红。
- **不掉回行式**：TUI 里任何一步都不准落到引擎的行式提示（`input()`、`Y/n`、编号菜单）上，
  也不准提示“请运行 `nyxuri xxx`”。确认、多选、输入一律在活动区完成。
- **外部程序**：pacman / AUR 助手在 TUI 确认后以非交互方式执行，输出在活动区滚动显示
  （Omarchy 式日志尾：最近 8 行、dim、行首 `→`、截断到栏宽），结束后日志尾收掉，
  写一行结果进记录；失败时把末尾输出一并写进记录。
- **唯一的终端交接**：sudo 密码（执行前统一 `sudo -v` 一次）和用户主动打开的 `$EDITOR` / diff 分页器。
  交接只发生在两次 inline 运行之间，回来后接着下一个活动区，不重新进菜单。
- **一次进入，干完退出**：从主菜单进去的流程走完回到主菜单，不中途退出程序把用户扔回 shell。

## 7. 线框

以下线框里 `│` 外侧的留白就是居中栏的左右边距（示意 100 列终端，栏宽缩写）。

进入主菜单，插件工坊（焦点详情是框下的 dim 行，不做双栏）：

```
                          ███╗   ██╗██╗   ██╗██╗  ██╗    ██╗   ██╗██████╗ ██╗
                          ...（字标，强调色，栏内居中，活动区的一部分）
                                   nyxuri 0.9 · ~/.config

              ● 插件工坊
                └ 14 个插件，3 个偏离

              ╭──────────────────────────────────────────────╮
              │ ❯ ◉ niri          default     synced         │
              │   ◉ noctalia      default     drifted !      │
              │   ◯ mango         —                          │
              │   ◉ kitty         default     synced         │
              ╰──────────────────────────────────────────────╯
                noctalia · 3 个文件偏离 · 包 quickshell
                ↑↓ 选择 · o 启用 · f 停用 · d 差异 · esc 返回
```

破坏性确认：

```
              ● 停用 mango
              ╭──────────────────────────────────────────────╮
              │ 将删除 ~/.config/mango（保留 __custom__.conf）│
              │ ❯ 1. 取消                                     │
              │   2. 停用                                     │
              ╰──────────────────────────────────────────────╯
```

决定之后，活动区收进记录：

```
              ● 停用 mango
                └ ✓ 已移除 4 个文件，保留 1 个
```

装包进度（Omarchy 式日志尾，结束后收成一行）：

```
              ● 启用 noctalia
                ⠹ 安装 quickshell noctalia-shell
                → (3/7) installing qt6-declarative
                → (4/7) installing quickshell
                → ...
```

```
              ● 启用 noctalia
                └ ✓ 装了 7 个包，部署 12 个文件
```

## 8. 实现约束

- 样式只写在 `nyxuri/tui/nyxuri.tcss`；颜色、间距、断点不进 Python 代码。
- Textual 内置组件只当骨架用，默认样式全部覆盖；禁用 `Header` / `Footer` / 默认按钮。
- `textual` 只许出现在 `nyxuri/tui/`；引擎侧交互走纯标库行式基座，视觉规则（符号、色角色）与本页一致。

## 9. 验收

- kitty 实机，80 / 120 / 200 列各走一遍；拖动改宽时活动区重排不残影。
- 同一屏内记录、框、提示行的左边线逐列对齐；字标在栏内居中，左右留白差 ≤ 1 列。
- 退出后历史里只剩记录，没有半截框。
- 中文、全角符号与英文同列对齐。
- 换一套 kitty 主题，TUI 颜色跟着变，无硬编码色残留。
